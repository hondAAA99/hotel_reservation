CORS Policy Tester

Run cross-origin requests against a target URL and see how it responds.
This tool must be run from a page opened directly in your browser (e.g. double-click the downloaded HTML file). Browsers block "mixed content" — an https:// page cannot fetch an http:// URL. Opening this file locally (file://) avoids that restriction. If you host this tool on an https server, point it at an https target instead.
If your target is an ngrok free-tier URL: click "Open target in new tab" above, click Visit Site on the page that appears, then come back here and run the tests in the same browser. That sets a 7-day cookie that bypasses the interstitial for every request — including the preflight OPTIONS requests, which can't carry the custom header workaround.
